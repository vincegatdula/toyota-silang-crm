About

Toyota CRM — Silang, Cavite

Frontend-only dealership CRM. HTML + CSS + JavaScript + IndexedDB. No server, no database, no internet required. Data lives in this browser. A future cloud backend can replace the storage layer without rewriting the UI.

Storage technologyIndexedDB (data) · localStorage (UI preferences only)
Offline supportWorks offline via service worker; data stays on this device
Security noteThis app has no passwords or API keys. Data access is only as private as the device you use.
